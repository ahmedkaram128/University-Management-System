# University-Management-System


🚀 Project Overview
Managing a university workforce involves complex hierarchies, distinct roles (Admin, HR, Faculty, Staff), and specific workflows for leaves and performance evaluations. This project digitizes these operations to ensure data integrity and efficiency.

Key Objectives:

Centralize employee data storage.

Automate payroll calculations and leave requests.

🛠️ Tech Stack

-- Microsoft SQL Server (T-SQL)
  -Extensive use of Stored Procedures, Triggers, and complex Relations.

-- C# (.NET)

Frontend: HTML5, CSS3

Tools: Visual Studio, SQL Server Management Studio (SSMS)

✨ Key Features
1. Role-Based Dashboards
Admin: Full control over system settings, department management, and adding new HR personnel.

HR Manager: Manage employee records, handle recruitment, and oversee payroll generation.

Employee (Staff/Faculty): View personal profile, check attendance, and request leaves.



🗄️ Database Structure
The backbone of this project is a relational database designed to handle complex university data. Key components include:

Stored Procedures: Used for secure data manipulation (e.g., RegisterUser, ApproveLeave).
Triggers: ensuring data consistency across tables (e.g., updating leave balance automatically).
